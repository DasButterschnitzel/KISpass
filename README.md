# KISpass

## Die Mitte — Motion Identity

[`die-mitte-motion/`](die-mitte-motion/) contains the motion graphics identity for
**Die Mitte**, the fictional party of a film production (*fiktive Partei · Filmrequisite*):
logo reveal, cinematic opener, slogans, title cards, lower thirds, information
graphics, transitions with alpha, social animations, closing card, a seamless stage
loop (also as a 12:5 LED-wall master) and a showreel — each composed individually for
16:9, 9:16 and 1:1.

- **Showcase:** `die-mitte-motion/showcase/Die-Mitte-Motion-Showcase.html` (single file, plays everything live)
- **Masters:** `die-mitte-motion/exports/video/` (MP4 25p, BT.709 · overlays as MOV/WebM with alpha)
- **Style frames & contact sheets:** `die-mitte-motion/exports/stills/`, `die-mitte-motion/exports/contact-sheets/`
- **Guidelines, specs, rendering:** [`die-mitte-motion/README.md`](die-mitte-motion/README.md)
